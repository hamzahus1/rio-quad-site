# Portfolio site

Personal product-design portfolio (Next.js + Tailwind).

## Run

```bash
npm run dev
```

Open http://localhost:3000

## Customize

Edit `src/data/site.ts` for name, bio, projects, FAQs, portfolio tabs/items, and email.

## Notes

- No third-party analytics, embeds, or remote CDNs
- Portfolio cards are local placeholders / UI previews
- Tabs: Product & web · App · UI components
